05 DEPLOYMENT

Local dev vs Cloud Run

Same code path, two operating modes. Choose based on whether schedules must survive laptop shutdown.

Local (dev / demo)

  • SQLite file in backend/meta_insights.db
  • uvicorn :8001 + vite :5174; reload on save
  • Schedules only fire while laptop awake and process running
  • No infra cost; fastest iteration loop

Cloud Run (production)

  • TiDB Cloud as managed MySQL; schema auto-migrates on boot
  • Single container (Vite build → FastAPI static mount)
  • Cloud Scheduler triggers /api/schedules/{id}/run at the exact cron time
  • --cpu-throttling --min-instances=0 --max-instances=1 ≈ USD $0–2/month
